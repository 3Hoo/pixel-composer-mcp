# 아이템 아이콘

## 추가로 물어볼 것
- **크기:** 16, 24, 32, 48 등. 인벤토리 칸 크기와 여백, 칸 배경색.
- **세트 일관성:** 같은 세트의 기존 아이콘을 받는다. 팔레트, 외곽선 규칙(색, 두께, 바깥만 두를지), 빛 방향(보통 왼쪽 위), 디테일 밀도를 거기에 맞춘다.
- **각도와 구도:** 검은 대각선인지, 물약은 정면인지 등. 세트의 관례를 따른다.
- **등급 변주:** 희귀도에 따라 색을 바꾸거나 테두리·빛을 따로 둘지.
- **애니메이션 여부:** 정지 이미지인지, 반짝이는 루프인지.

## 구조
- **실루엣 먼저.**
  - `Node_Shape`(Full Image 모드에서 점 좌표를 픽셀로)나 `Node_Shape_Polygon`으로 큰 덩어리를 2~4개 만든다.
  - 1배 크기로 보고 무엇인지 읽히는지 확인한 다음에 세부를 넣는다.
- **명암:**
  - 덩어리마다 2~3단계면 충분하다(밝음, 기본, 어둠).
  - 빛 방향을 하나로 정하고 모든 덩어리에 같은 방향을 쓴다.
  - 입체 형태는 `Node_Normal_Light`나 3D 기본 도형 렌더로 명암을 얻은 뒤 팔레트로 고정할 수도 있다(⚠️ 미검증).
- **외곽선:** `Node_Outline`(✅). 너비 1, 안티앨리어싱 끔(6=False). 색은 세트 규칙을 따른다.
- **색 고정:** 마지막에 팔레트 `Node_Posterize`(2=True, 1=팔레트)를 둔다. 알파가 있는 그림이면 Alpha_Grey 마스크를 쓴다(`pitfalls.md`).
- **세트 제작:** 한 스크립트에서 크기, 팔레트, 외곽선을 공유하고, 형태만 바꿔 여러 개를 낸다.

## 검사
```
check_sheet(icon, "pixel", max_colors=<세트 기준>)
```
- 하드 알파, 색 수, 떠도는 색, 외톨이 픽셀을 본다.
- 눈으로는 1배 크기로, 실제 인벤토리 칸 배경 위에서, 기존 세트 아이콘 옆에 놓고 본다.
- 디테일 과잉 신호:
  - 1배에서 구분되지 않는 1px 장식
  - 외톨이 픽셀이 많음
  - 기존 아이콘보다 색이 확연히 많음
