# 캐릭터: 보정 → 리깅 → 애니메이션

Pixel Composer는 캐릭터 그림을 처음부터 그리지 않는다.
- **원본:** 유저가 Aseprite로 찍거나, AI로 생성해서 받는다.
- **이 스킬의 범위:** 픽셀아트 보정과 리깅·애니메이션.

## 추가로 물어볼 것
- **원본 파일:** `.aseprite` 경로(공백 없이), 캐릭터 크기, 바라보는 방향.
- **레이어 구성:**
  - 부위별(머리, 몸통, 팔 위·아래, 다리 위·아래 등)로 나뉘어 있는지, 레이어 이름 규칙은 무엇인지.
  - 나뉘어 있지 않으면 **유저에게 Aseprite에서 나눠 달라고 요청한다.** 에이전트가 마스크로 잘라내면 경계가 찢어져 보이기 쉽다.
  - 가려진 부분(팔 뒤쪽 몸통 등)이 그려져 있어야 회전했을 때 구멍이 생기지 않는다.
- **원본 상태:** AI 원본이면 손질이 얼마나 필요한지, 고정할 팔레트가 있는지.
- **동작:**
  - 종류(걷기, 대기, 공격 등), 프레임 수, fps, 루프 여부
  - 이동 동작이면 제자리에서 움직이는지(인플레이스)
  - 레퍼런스 애니메이션
- **출력:** 시트 배치, 프레임 크기, 피벗(발 위치).

## 1. AI 원본 보정 (⚠️ 노드 조합은 미검증, 노드별 기능만 확인)
1. 목표 해상도로 줄인다: `Node_Scale_Algo` 또는 `Node_Downscale`.
2. 팔레트를 고정한다: `Node_Palette_Extract`로 뽑고 `Node_Palette_Shrink`로 줄이거나, 게임 팔레트를 받는다. 그다음 팔레트 `Node_Posterize`(알파 마스크 포함)를 쓴다.
3. 알파를 정리한다: `Node_Threshold`(알파).
4. 외곽선을 넣는다: `Node_Outline`(✅). 원본에 외곽선이 없을 때만.
5. 지저분한 픽셀을 정리한다: `Node_De_Stray`(✅), `Node_De_Corner`.
6. `check_sheet`로 전후를 비교하고 결과를 유저에게 보여준다. 마지막 손질은 사람이 Aseprite에서 한다고 가정하고, 손볼 곳을 짚어 준다.

## 2. 리깅 (✅ 검증한 방식)
- **불러오기:** `add_node("Node_ASE_File_Read", x, y, file=<.aseprite>)`.
  - 출력 0은 레이어를 합친 그림이다.
  - 레이어별로 쓰려면 "Generate Layers"(입력 1, 트리거)로 레이어 노드를 만든다(⚠️ 트리거는 미검증).
- **뼈 구조:** `Node_Armature`의 노드 JSON에 있는 `bones` 트리를 파일에서 편집한다. 루트(`is_main`)의 `childs`에 뼈를 넣는다.
  - 뼈 하나 = 루트 뼈 dict 복사 + 새 `ID`, `name`, `direction`(도, 0=오른쪽, 90=위), `length`(px), `distance`, `parent_anchor`(true면 부모 뼈 끝에서 시작), `is_main=false`, `childs`.
  - 편집 후 다시 열면 앱이 그대로 받아들인다.
- **포즈:** `Node_Armature` → `Node_Armature_Pose`(입력 0). 다시 열면 뼈마다 변형 입력이 3번부터 생긴다. 값은 `[x, y, 회전, 크기]`이고 `set_keyframes`로 애니메이션한다.
- **바인드:** `Node_Armature_Pose` → `Node_Armature_Bind`(입력 1).
  - 그림 입력은 5번부터 6개 단위로 붙는다.
  - 그림과 뼈의 연결은 노드 `attri.boneIDMap`(그림 순서대로 뼈 ID 목록)에 적는다.
  - 출력 크기는 입력 0이다. 기본값이 1×1이므로 꼭 설정한다.
- **아직 확인 안 한 것:**
  - 그림이 뼈의 어디에 붙는지(위치 맞추기)
  - IK(`Node_Armature_IK`)
  - 메쉬 변형(`Node_Armature_Mesh_Rig`)
  - 걸음처럼 발이 미끄러지지 않아야 하는 동작
- **화면에서 하는 편이 빠를 때:** 뼈 위치와 그림 배치를 눈으로 맞춰야 하면, 유저에게 Pixel Composer 화면에서 뼈와 바인드만 잡아 달라고 한다. 에이전트는 포즈 키프레임과 출력을 맡는다.

## 3. 애니메이션 검사
- **루프:** 마지막 프레임에서 첫 프레임으로 매끄럽게 이어지는지 본다.
- **회전한 부위:** 픽셀 격자가 깨지거나 반투명이 생기기 쉽다. 바인드 뒤에 알파 Threshold와 팔레트 고정을 다시 건다. 그다음 `check_sheet(..., pixel_scale=k)`로 검사한다.
- **눈 검사:** 프레임 나열과 GIF를 1배로 본다. 발 미끄러짐, 부위 사이 틈, 깜빡이는 픽셀을 확인한다.
