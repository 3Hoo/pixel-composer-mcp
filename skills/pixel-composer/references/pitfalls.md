# 함정 목록 (Pixel Composer 1.22.0.5 + pixel-composer-mcp)

실제로 겪은 것만 적는다. 증상 → 원인 → 대응.

## 앱과 연결
| 증상 | 원인 → 대응 |
|---|---|
| 노드를 만들자 앱이 멈춤 | 파일 대화창을 여는 노드(`Node_Image`, `Node_ASE_File_Read` 등). → `add_node(type, x, y, file=<경로>)`. MCP가 대화창 없는 생성 함수를 부른다 |
| 경로가 잘림, 파일을 못 찾음 | 콘솔이 공백으로 인자를 나눈다. → 작업 폴더·출력·입력 파일 경로에 공백을 쓰지 않는다 (프로젝트는 MCP가 사본으로 연다) |
| 긴 명령이 중간에 끊김 | Remote Terminal이 약 490바이트 뒤를 버린다. → MCP가 400바이트 단위로 나눈다. `run_command`에 한 줄로 긴 값을 넣지 않는다 |
| 명령 결과가 안 옴 | 앱은 응답하지 않는다. 직접 띄운 앱의 stdout `STATUS:` 줄과 파일 변화가 유일한 신호. 사용자가 띄운 앱에 붙으면(attached) 로그가 없다 |
| `set_input(reload=False)` 뒤 앱 화면이 옛 값 | 정상. 다음 save/export/편집 때 파일을 다시 읽는다 |
| `open_project` 결과에 `warnings` | 다른 PC에서 만든 프로젝트의 Export 경로가 없는 폴더. → `set_input(<export 노드>, 1, <새 경로>)` |

## 출력
| 증상 | 원인 → 대응 |
|---|---|
| 스프라이트시트가 비었거나 일부 프레임만 | `Render Spritesheet`는 타임라인이 렌더되는 동안만 프레임을 모은다. → export를 두 번 (첫 번째에 GIF 같은 애니메이션 export가 타임라인을 돌림). `Graph.export()`가 이렇게 한다 |
| `x.png`를 요청했는데 `x.gif`가 나옴 | 확장자는 Export 노드의 형식 설정(입력 3)을 따른다 |
| 시퀀스 export가 한 파일만 덮어씀 | 이름 템플릿(입력 2)에 `%f`가 없다 (예: `%d%n_%f`) |
| PNG export가 빈 이미지 | 단일 PNG는 현재 프레임(보통 0)만 찍는다. 0프레임에 아무것도 없는 애니메이션이면 비어 보인다 |

## 키프레임
| 증상 | 원인 → 대응 |
|---|---|
| on/off가 중간 프레임에서 섞여 켜짐 | bool 키프레임도 보간된다. → 바뀌기 직전 프레임에 이전 값을 한 번 더 키한다 (`graph.switch(on, off)`) |
| 키를 건 입력에 `set_input`을 했더니 애니메이션이 사라짐 | 정상: 고정값이 키프레임을 대체한다 |

## 파티클 (`Node_Particle`)
| 증상 | 원인 → 대응 |
|---|---|
| Burst 스폰이 아무것도 안 나옴 | 이 방식으로 다룰 때 Burst는 렌더되지 않았다. → 스트림(16=0) + 스폰 bool(27)을 짧게 켜는 키프레임 (`graph.emitter`) |
| 중력이 안 먹음 | `Use Physics`(57)를 켜야 중력(19)이 적용된다 |
| 다시 빌드할 때마다 모양이 다름 | 시드가 고정되지 않음. 최고 높이가 몇 px씩 달라진다. → 다시 빌드한 뒤 항상 `check_sheet`를 다시 돌린다 |
| 한 번에 뿜은 덩어리가 통째로 떠오름 | 속도 범위가 좁다. → 속도 범위를 넓혀 기둥처럼 퍼지게 |
| VFX 그룹 렌더 시 `surface_wcache` 에러 | `Node_VFX_Group_Inline`. → 쓰지 않는다. `Node_Particle`을 쓴다 |

## 도형 (`Node_Shape`)
| 증상 | 원인 → 대응 |
|---|---|
| 프레임 전체가 한 색으로 칠해짐 | 넓이가 0인 Triangle/Quadrilateral은 화면을 채운다. → 숨길 때는 넓이를 남긴 채 화면 밖으로 옮긴다 |
| 좌표가 0..1로 해석됨 | 위치·영역 입력의 단위. → `absolute=True` (unit 0 = 픽셀) |

## 픽셀화
| 증상 | 원인 → 대응 |
|---|---|
| 맨 위 행에 바닥 빛이 나타남 | `Node_Blur` 크기 6 초과는 가장자리를 감싸 반대편으로 넘긴다. → 6 이하 |
| 팔레트 Posterize 뒤 프레임 전체가 불투명 | Posterize는 알파를 무시한다. → Threshold(알파) → `Node_Alpha_Grey` 마스크를 Posterize 마스크 입력(12)에 |
| 픽셀 버전 외곽에 어두운 점선 | 안티앨리어싱된 가장자리가 premultiplied alpha로 어두워져 가장 어두운 색으로 붙는다. → 도형 위주 그림은 알파 Threshold 0.5 (부드러운 파티클 위주는 0.2) |
| 블룸이 프레임 전체에 옅게 깔림 | 블룸이 거의 0인 알파를 넓게 퍼뜨린다. → `Node_Level`로 알파 4% 미만을 잘라낸다 |
| 생성기 출력이 회색뿐 | MKFX 등은 흑백을 낸다. → `Node_Colorize` 또는 팔레트로 색 입히기 |
